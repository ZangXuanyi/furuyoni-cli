# 规则裁定总表（唯一权威裁定文件）

本文件汇总：README 原有的裁定（2026-10 之前，编号 1~109）与 2026-10 严格审计期间需求方新裁定的条目。
`rules/` 是卡面文本，本文件是**语义裁定**；两者冲突时以本文件 + `rules/` 最新文本为准。

> 使用约定：规则问题先在这里查；新增裁定请追加到文末并编号，同时在 `docs/known-issues.md`
> 中把对应条目标记为已解决。

## A. 2026-10 新裁定

### A.1 基本与通用

* **达人距离 = 近身距离**：双方公用的属性（默认 2），只影响基本动作“前进”（当前距 > 达人距）与
  “离脱”（当前距 ≤ 达人距）的合法性；`圈域` +1、`引力场` -1。**不是攻击距离修正**
  （README 旧裁定 21 关于“圈域=我方攻击距离远+1”的说法作废）。
* **可选性**：`气动` 强制；`岚之力` 可以选择“不使用”，但一旦使用层级强制；`阵风祭天式` 的“至多 2 次”、
  `流转爪`、`风雷的智慧`（回牌山部分）均为非强制；`风雷的智慧` 的加槽来自通用规则，强制。
* **追加基本动作**受“本回合不能执行基本动作”（`二重奏·吹弹阳明`）与 `夜叉`“引擎空不能进行基本动作”限制。
* **数值替换先于数值增减**（官方 QA）：`天地反驳` 的伤害互换发生在 `next_attack_mod`、附加零件等**所有**增减之前。
* **事件归属**：光环只响应“自己的”事件/牌（`森罗判证`/`翩然如织`/`模块化`/`魔能吸收`/`伴奏` 等）；
  `伞飞转` 也只在“你自己（非本牌）切换武器”时触发。
* **“结算完毕”包含落空与被打消**：`圆环轮回旋` 在对手攻击**任何**结局（命中/落空/被打消）后都触发。
* **`迟缓毒`**：“不能使用攻击牌”包含作为对应打出攻击牌；但**牌效生成的攻击不是“使用”**，不受限。
  `二重奏·弹奏冰瞑` 的“不能攻击”则连生成的攻击一起禁止。
* **`信条`** 的“对手死亡”可以被 `最后的结晶` 复活抵消。
* **`诸式理解`**（神算）中“若该牌有全力词条则结束你的回合”应理解为该牌获得**终端**（结束当前阶段）。
* **`诡辩`/`引用` 借来的牌**：使用过程中视为在**使用者**的场上（付与在使用者的付与区生效、献由使用者支付、
  光环归使用者）；一旦该牌离场（付与弃置等），**归还对方**，进入**对方的弃牌堆**（`引用` 的“盖伏之”进对方盖牌堆）。
  实现上用 `CardInstance.holder`（在场归属）与 `owner`（真正持有者/最终去向）区分。

### A.2 具体卡

* **`合奏`** 的伤害统一为 **3/0**（两版一致）。
* **`问答`**：`【2-5 3/0】`，算命中。`攻击后`：若对手选择由命承受伤害，则盖伏**对手**牌库顶 3 张；
  随后你执行一次基本动作，对手执行一次相同的基本动作。旧的 `evade`（选择免伤）机制已移除。
* **`立论`** 没有独立的“攻击后”段落 ⇒ 其“对手牌库≥2 则改为盖伏 2 张”在**结算时重判**，不在声明时锁定。
* **`萨利亚的杰作`**：`燃烧X` 需要“用尽”不少于 X 才能打出（不允许不完整燃烧）；“不能恢复时不能打出燃烧牌”。
* **`虚鱼`** 给的额外设置牌进**牌山**；“将要重铸”**不**包含“改用电子设置”这一流程（胧文书维持现状）。
* **A1（新型）的变形池**继承未被替换的 O 变形（`娜迦` 保留；A1-TR1 紧那罗↔O-TR1 夜叉，A1-TR3 阿修罗↔O-TR3 迦楼罗，A1-TR4 提婆为新增）。
* **`夜叉`** 变形时让**对手**的下一次准备阶段少抽一张牌（不是变形者自己）。
* **`炼成攻击`** 不可被封印（`unsealable`），也不可被对手选择（`no_opponent_pick`）：对手的
  `论破`/`完全论破`/`引用`/`诡辩`/`探查测度` 的候选池均已排除它。
* **`紧那罗`** 变形时**盖伏**对手的牌库（不是弃置）。
* **`提婆`** 触发条件为“对手的弃牌数量**变为** 0 以外的偶数的那一刻”。
* **Thallya 卡面修订**（`rules/11-thallya.md`）已同步：`震荡波` 补燃烧、`倒车`/`蒸汽大炮` 燃烧移到打出时、
  `轰鸣` 燃烧 2 可选、`换档` 补对应、`阿尔法之刃` 射程 `1,3,5,7`、`黑盒` 仅引擎为空时可用。

### A.3 新增女神（13 虚路 / 14 仄佳）

* **铳镰禁真红凶弹**（官方唯一禁卡）：当玩家同时选取 `himika` 与 `utsuro` 时，`真红凶弹`（03-Himika O-S1）
  不能加入构筑。已实现为数据驱动的**禁用组合表** `content/combo_bans.json`（便于后续加村规）。
### A.4 凝努（15）

* `冻结`：把冰晶置入对方装中，与樱花结晶**共用装的上限**；冰晶不视作装、不能承伤（除 `冰凌包覆` 外）。
* 被冻结时 `聚气` 改为**移除 1 个**冰晶（冰晶消失，不移入气）。
* `装附`/`前进` 的合法性受冰晶占位限制（`aura + ice <= 装上限`）。
* `冥沼式` 弃置时的“再次使用”：**支付 2 气** → 回付与区 → 4 虚到这张牌上 → 再次结算展开时。
* `绝对零度` 全开：先进行那次攻击，**然后照常**装附 1 次（敌装冰晶 ≥ 3 时再 1 次）。
* `吹雪式` 的“即再起：敌装变满时”由引擎事件 `armor_full` 驱动；**本牌自己造成的冻结不触发**（把本牌作为 cause），
  其它任何原因（含对手自己装附）使敌装变满都会触发。
* `冰凌包覆`：虚不足 5 时**尽量移动**；“至少冻结了 2 次”按实际放入的冰晶个数计。
* `冻僵` 只禁止对手**聚气**（前进照常）。
* `残烛式` 的费用/纳为动态（3+X-Y / 6+X-Y，X=对手命，Y=双方装中冰晶总数，负值取 0）。

### A.5 八叶（16）

* `镜映` = 你的装/气/命中与对手对应区域结晶数相同的区域数（`ctx:mirror()`，0..3）。
* `完全态`（升级）：`CardDef.upgrade` 指向升级后的牌名，`ctx:upgrade_card(inst)` **就地**替换 def 并保留所在区域；
  升级版牌带 `complete = true`，`ctx:count_complete(p)` 统计完全态数量（徒寄花）。
* A1/AA1 **只有 1 张切牌**：该形态的切牌带 `solo_specials`，`deck_def_ids` 会整体取代 O 的切札线。
* `AA1（魂）`是第三个 form（按 A2 处理），引擎按 form 字符串枚举，无需特判。
* `八叶镜陨茕樱`（A1-S1）的"限制距离0-7" = 展开中把**有效距离**限制在 0..7（`limit_distance`）。
* `四叶镜的童谣`"若这张牌是全力牌，终端" = 使用那张付与牌后**结束当前阶段**（`ctx:end_current_main()`）。
* `盟誓`"选择一项：A或B；C或D" = 4 个候选里**整体选 1 项**。
* `双叶镜的祟神`：若自命 < 敌命，则打消被对应的攻击，并用 `ctx:copy_attack()` **精确复制**一份
  （其他所有效果修正后的距离/伤害/超克/终端 + 攻击后效果 + 女神/通常/切札判定）反过来攻击对手；
  否则若被对应的攻击不是切牌则打消之。
* **回忆区**：新增 `Zone::Memory`；对手的 observation 只给 `memoryCount`（内容保密），自己的 observation 给牌名。
  `ctx:to_memory` / `ctx:memory_draw` / `ctx:all_normals_to_memory(p, 保留的实例)`；回忆区不结算弃置时效果，其上结晶移到虚。
* `此目所及之物与世` 的三条"使用后"分别接到引擎的**抽牌**与**重铸命伤**两处替换点，以及"从回忆区加入手牌时可升级"。
* `散樱代的旅途`：四项奖励，**双方每个回合开始时各自动推进一项**，第二次回到起点时结算终幕。
* `此心所念之神与魂`"使用后：代替对应" = 在 `attack_declared` 时机触发，因此**无视"不可对"**（它不是对应行动）。

### A.6 神居（21）

* `诅咒`：**诅咒 >= 16 或 命 == 0** 即死亡。你的回合开始时（仅当你这局用了神居）：
  命 5-9 → 被诅咒 1 次；命 < 5 → 被诅咒 2 次。诅咒致死时命转为气（保持结晶守恒）。
* 卡面上"诅咒N：..."均为**可选**：诅咒 N 次换取该条的强化。
* `血飞沫`：任何**进入其持有者对手之装**的樱花结晶改为进入虚，并每次从此牌上移 1 个献到虚。
* `阡`：本牌弃置前**对手不会死亡**（`check_win` 里对死亡方做保护判定）。
* `晓`：`prevent_response` = 阻止对应——通常牌对应：此攻击 -1/+0，对应牌进弃牌堆；
  切札对应：-1/-1，对应牌仍需支付费用并置为使用后状态；攻击后晓移出游戏。
  注：`此心所念之神与魂` 替代对应的行动**不算对应**，所以能防止晓的伤害。
* `尸`：本回合对手下一次攻击必须额外弃置一张该女神的牌作为费用（`extraAttackCostGoddess`）。

* **同一时点的多个触发**：结束阶段的所有触发视为同一时刻，由**当前玩家**决定结算顺序；
  准备阶段各付与牌的“樱花结晶 -1”同样视为同一时刻，由当前玩家决定顺序。（引擎已实现：结束阶段事件
  `end_phase_start`/`turn_end` 逐个询问当前玩家；准备阶段的 -1 也逐个询问。）
* `虚伪`“对手的攻击距离-1”= **只缩近端**（`shrink_near(1)`）。
* `双掌生花`的“装附”替换：**自装满也可以**（结晶直接放到该牌上），但**必须有虚**；打出时的那次装附不替换。
* `熠熠见繁樱`的“再起”**保留**牌上的 X 结晶（`keep_crystals_on_reset`）。
* `再生`→`樱飞翅`：`樱飞翅` 进入**弃牌堆**（与 `樱飞翅`→`再生` 一致）。
* `绽放`是否可选按卡面“你可以”字面判定；写“放到抽牌堆底或弃牌堆”的必须二选一。
* `四季轮回`的“从追加牌区移出”由引擎事件 `extra_gained` 广播（任何追加牌离开追加区时触发）。
* 虚路 `灰尘` = 虚 ≥ 12；仄佳 `绽放` = 打出后把该牌**移出游戏**，换成指定追加牌
  （见 `content/honoka.lua` 的 `bloom()`）；仄佳也用到的 `光辉` = 虚 ≤ 5。
* 追加牌的去处以卡面为准：写“放到抽牌堆底或弃牌堆”的**必须二选一**；写“以未使用状态获得…到切牌区”的
  进切牌区未使用态。

## B. 早期裁定（编号 1~109，2026-10 之前）

以下来自与需求方的确认，作为后续阶段的基准：

1. `决死` = 自命 ≤ 3；`八相` = 自装 ≤ 1。已作为接口 `ctx:desperation/hasso` 暴露；26 女神各自的词条后续提供。
2. 对应牌**本身**不能被对应；常规打出时则可以被对应。对应牌生成的**虚拟攻击**可以被对应。
3. 同时触发多个效果时，**当前玩家**选择先结算哪一个。
4. `纳 X`：由付与牌控制者决定从虚/自装各取多少、顺序自选；不足 X 时尽量多取，>0 即留存，=0 则打出即进弃牌堆。打出付与的结算顺序为 **展开时 → 放献 →（若无献则）弃置时**；即“虚+自装=0”时依然触发 `展开时` 与 `弃置时`，只是没有 `展开中`。
   付与上的结晶掉落（含每回合开始 -1、牌离场）**进入虚**，不会被消耗；因此 `双方命+气+装 + 距 + 虚 + 付与上的结晶 == 36` 恒成立（除非某牌显式从游戏外取得/移出结晶）。
5. 攻击须在声明时合法；被对应导致距离改变后**重检**，唯有 `锁定` 跳过。攻击落空则 `攻击后` 不结算；切札无论如何都展开，`使用后` 光环仍生效。
6. X/Y 的装伤侧实际为 `min(X,5)`，`超克` 不取 min。
7. 重铸 = 1 命→1 气并洗弃牌堆+盖牌堆+牌山，不触发破绽；牌库充足时也可主动重铸，不足时也可不重铸。部分牌有免费重铸效果（后续）。
8. 每次失败的抽牌尝试各触发一次不可对应的【0-10 1/1】焦躁伤害。
9. 基本动作由玩家在“扣 1 集中力 / 盖 1 张手牌”间选择；切札不能用于盖伏支付。
10. `破绽`：付与展开时受到任何命伤（重铸除外）即将其全部结晶移到虚、盖伏该牌且不结算弃置时效果（进盖牌堆）。
11. 双方第一回合（T1、T2）都跳过准备阶段；游戏前各抽 3 并各换牌一次（秘密）。
12. 命归零判负；40 回合无结果判平局；特殊胜负留接口。
13. 三拾一舍 / 构筑 / 换牌均为**秘密且强制同步**（Phase 2+ 实现；Phase 1 为固定教学卡组，但构筑与换牌已实现秘密同步）。
14. 时间制度（每回合 3min + 留存 6min）与非法动作容忍度见 `Config`，Phase 1 预留未强制。

### Phase 2 追加裁定

15. `两侧伤害`：同时承受装伤与命伤（装不足则把全部装移虚，再接命伤），承受方无选择。
16. `视作装`：有效装 = 实装 + 该牌上结晶；承受装伤时**优先耗尽卡上结晶**（进虚）。
17. 条件强化时机：攻击自身的强化在**打出（声明）时**判定并锁定（仍可被对应减少）；`攻击后` 类效果在攻击后结算时判定。
18. `下一次攻击`修饰：作用于**任意**下一次攻击（含虚拟/衍生），**打出即消耗**（无论命中/被对应）；`回燃` 的带条件修饰保留至出现符合条件的攻击（跨回合）。
19. 牌效中的“执行基本动作”：无需集中力/盖牌，但仍受正常合法性与上限约束；`AA到BB` 一律“尽量多移动”。
20. `晴舞台` 实为 `终端` + `展开时：集中力变 2`（仅结束主要阶段，仍需盖伏）。
21. `圈域`：**达人距离（近身距离）+1**，即改变双方“前进/离脱”的阈值（不是攻击范围）；其结晶移除（按正常规则）一律进【距】。`引力场` 的“达人距离减小 1”同理。
22. `迷烟` 对双方牌效生效。
23. `无穷之风`“公开手牌”仅当下一次公开（对 CLI 无持续影响）。
24. `连射` 计数：本回合打出的所有牌（含作为对应打出的），当前这张计入。
25. `气焰万丈`：作用于另一柱女神的任意攻击（含切札与衍生）。
26. 变格在**选女神时同时选形态**（Phase 3 实现；数据层已用 `goddess`/`form`/`num` 预留）。

### Phase 3 追加裁定

27. 伤害值 `0` 是**真实值**（如 `合奏` 3/0），对手完全可以选择承受 0；只有**未写**才是 `-`。
28. `问答`（2026-10 修订）：【2-5 **3/0**】。算命中（`攻击后` 与 `on_resolve` 都触发）。`攻击后`：若对手选择由命承受伤害，则盖伏**对手**牌库顶 3 张（进盖牌堆）；随后你执行一次基本动作，对手执行一次相同的基本动作。旧的 `evade`（选择免伤）机制已移除。
29. `畏掠`：若对手集中力为 0，则由攻方选择承伤侧；其“攻击后（心境）”按本牌对对手造成的**实际伤害**削弱被对应的攻击。
30. `伴奏`：在对手本回合**第一次攻击声明时**修正（移去不可对、-1/+0），早于对应窗口。
31. `终始`：对手装的数目在本回合**第一次变化**时触发，立即结算，可选。
32. `徒寄之八重樱`：装上限 8 在该牌正面向上（已使用）期间生效；“回合开始时”攻击在回合开始触发。**若该牌被翻回未使用（如神座渡重置），装上限恢复，并把自装中超过上限的部分移入虚**（`reset_special` 会 `clamp_aura`）。
33. `神座渡`：X 在**付费用之前**锁定；随后免费装附/聚气、重置 X 张已使用切牌（自身除外）、本回合手牌上限 +X。
34. `绝唱绝华`：在被对应的攻击结算后判定“用装承伤且自装为空”，成立则结束对手主要阶段（用 `on_resolve` 延迟回调实现；已有单元测试）。
35. `悠久之雪`：判定依据是“对手**选择**承装伤”这一侧，即使因对应把装伤降到 **0**，仍算选择承装伤并触发（0 是真实数值；已用单元测试覆盖）。
36. `二重奏`（弹奏冰瞑/吹弹阳明）：费用-1 条件分别为八相/心境；本回合禁攻击/禁基本动作；`使用后` 持续与“因攻击受命伤”即再起按卡面。

### Phase 5（Oboro）追加裁定
