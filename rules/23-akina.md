# 23-Akina 源上安琪娜

【象征武器】算盘（O）。

【机制】资本～初始股价为2，有特殊的“股市”区。当敌人的命受攻击伤害时，股价+2；投资时，股价+1；当你的命受攻击伤害时，股价-1；套现时，股价-2。股票价格可能为1 2 3 4中的任意数值。
- 投资流程：我方洗牌时，或回合结束且本回合内没有套现时，可以将一张有“投资券”词条的牌（恫吓、直接金融、正解）从正面向上翻至背面向上（确实可以通过此法重置“正解”），并支付投资资金（股票价格为1时将一片樱花结晶从虚移到股市，2则从我方装，3从我方气，4从我方命），然后按规则增加股价。
- 套现流程：回合开始时可以套现，有的牌的效果也会套现。将股市中一片樱花结晶移到虚，然后套现（股价为1时从虚移动1片樱花结晶到我方装，2从敌方装到我方装，3从敌方气到我方装，4从敌方命到我方装），然后按规则降低股价。
- 资本：一个玩家装、气、股市中所有樱花结晶的和称为这个玩家的资本。不控制安其那玩家的股市视作0。

## 算盘

- O-N1 算盘珠：【1-6 1/0】攻击后：选择一项：获得1集中力；套现一次；1自装到股市。
- O-N2 恫吓：【4 -/0】投资券。若你的资本比对手多，则此攻击获得+0/+1。攻击后：若你的资本比对手少，则本牌结算完毕后被盖伏。
- O-N3 交易：【1-5 2/0】终端。攻击后：若你的资本比对手多，你可以执行一次基本动作。攻击后：若你的资本比对手至少多3，则可以将你的弃牌堆中一张非安琪娜的卡牌拿到手中。
- O-N4 投机倒把：选择一项：2自装到股市，或2虚到自装。
- O-N5 算法：对应。本回合内，所有攻击的距离都获得距离扩大（近1）和距离缩小（远1）。
- O-N6 乱拨：【纳2】限制距离0-3。展开时：2敌气到距。展开中：若此牌上的樱花结晶将被移除，将其移至敌气而非虚。
- O-N7 直接金融：全力【纳2】投资券。破绽。展开时：1敌装到自装，你可以支付1集中力再执行一次1敌装到自装。弃置时：进行攻击【2-5，1/0】。
- O-S1 差列递归征税法（股价）：进行攻击“【0-10 -/1】这个攻击被任何牌对应时，打消自身（无论对手的对应牌是什么）”。若你的资本大于对手，则你必须再使用一次这张牌（需要支付费用），直到你的资本不大于对手为止。
- O-S2 大衍算科手打表（0气）：对应【0-10 2/0】攻击后：从自己的气、命、股市中各移动一片樱花结晶到自装。
- O-S3 仙霄鬼泉天元术（1气）：【纳1】展开时：4自命到自气。展开中：这张牌上的樱花结晶不能被除了本牌外的任何方式移除。当你死亡时，4自气到自命，然后移除这张牌（这张牌上的所有樱花结晶移到虚）。
- O-S4 源上安琪娜的正解（股价）：距离限制0-7。投资券。你可以选择立即套现一次，然后2虚到自装，然后将此牌移出游戏。使用后：你每回合开始时可以用1自装到自气来替代套现操作。

若切牌的费用是股价，则该牌的费用不能被其他任何方式改变，必须等于当前的股价。
