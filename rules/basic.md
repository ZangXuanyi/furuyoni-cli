# 《散樱》基本规则

## 游戏进程

### 游戏初始化

将版面初始化为：
- 双方命（Life）初始化为10。如果一个玩家的命被清空，则他输掉游戏。命的最大值为10。
- 双方装（Armor）初始化为3。装可以替代命承受伤害。装的最大值为5（但可以改）。
- 双方气（Flare）初始化为0。气用于打出一些强力的牌。气没有最大值。
- 场上距（Distance）初始化为10。距代表了双方的距离。距没有最大值。
- 场上虚（Dust）初始化为0。虚代表“未被任何一方支配”的能量。虚没有最大值。

这些数值都不可能为负也不可能为小数，所以你可以用无符号整数。

### 游戏前

- **三拾一舍**：双方各自选择三名女神，随后由对手选择一柱禁用，这样双方各剩下2柱可以使用。
- **眼前构筑**：每一柱女神会提供7张常规牌、4张切牌。由于每个玩家有2柱女神，所以实际上有14+8张牌可用于构筑。双方要从这些牌中选出7张常规牌、3张切牌，其他的牌就移出游戏不被使用。双方都不会知道对方将哪些牌加入了构筑。
- **决定先后手**：随机决定谁开局。先手玩家的集中力（Vigor）为0，后手玩家的集中力为1。集中力可以用来执行基本动作。
- **洗牌**：双方将切牌背面向上放在自己的切牌区，其他的牌洗混放在自己的牌山。双方都有自己的牌山、切牌区、弃牌堆、盖牌堆等，不能混淆。
- **获取初始手牌**：双方各抽3张牌。限一次，可以选择将其中任意多张牌放在自己牌山底并抽取等量的牌。随后先手玩家的第一个回合开始。

### 游戏中

每个回合分四步：准备阶段、主要阶段、盖伏阶段、结束阶段。
- 准备阶段：依次执行以下四步：
    + 集中力+1。如果集中力大于等于2则不加。
    + 各付与牌上的樱花结晶-1。如果存在多个付与牌，可以按任意顺序移除其上的结晶。
    + （可选）重铸牌库，即受到1命伤、将弃牌堆、盖牌堆、剩余的牌山洗混，重构成新的牌山。
    + 抽2张牌。每有一次失败的抽牌尝试，受到一次无来源的、不可对应的【0-10 1/1】焦躁伤害。
- 主要阶段：以任意顺序、任意次数执行基本动作、打出牌；或打出一张全力牌。基本动作包括以下几个，每执行1次基本动作都需要扣除1集中力或盖伏一张手牌（将牌背面向上置入盖牌堆）。如果无集中力可扣，或无牌可盖，或不能按规则移动樱花结晶，则不能执行基本动作。
    + 前进：1距到自装，且当前距离大于近身距离。（默认情况下，近身距离为2，但可以被牌的效果改变）
    + 后退：1自装到距。
    + 装附：1虚到自装。
    + 聚气：1自装到自气。
    + 离脱：1虚到距，且当前距离小于等于近身距离。
- 盖伏阶段：主要阶段结束后，如果手牌数量大于等于3，需要盖伏手牌直到手牌数量小于等于2。
- 结束阶段：结束你的回合。部分效果会在这个时候结算。

双方的第一个回合都不执行准备阶段。双方轮流执行其回合，直到游戏结束（如一方命归零、或特殊胜利、特殊失败等）。

## 关于牌的说明

### 基础牌

基础牌有三个主要的类别，和2个次要的类别。基础牌打出时，先结算其效果【注释：可以压进一个临时的栈。因为该牌的效果可能是使用其他牌、生成虚拟攻击、被对应等，当该效果结算完毕后弹栈】，效果结算完后再进入弃牌堆。

主要类别：
- 攻击：有属性“攻击距离”和“攻击伤害”。攻击距离一般是一个区间，但也有离散的情形，是该攻击能覆盖到的范围。如果当前距不满足该攻击的攻击距离则不能使用该攻击牌。攻击伤害是一个二元组，一般记作X/Y，由被攻击者选择受到X装伤或Y命伤：受到装伤时，将X个樱花结晶从装移到虚；受到命伤时，将Y个樱花结晶从命移到气。如果装小于X，则不能受装伤，只能受命伤。有时候该攻击可能是X/-或-/Y【注释：你可以使用std::nullopt或类似的功能实现】，那么对手必须选择有数值的一边承伤，此时如果装不够X则将所有装移到虚。特别的，在一侧溢出的伤害不会反馈到另一侧；此外，X不会大于5（也就是说，即使因为一些动态效果，X大于5，只要对手有5装，就能吃下这次攻击），除非该攻击有词条“超克”。
- 行动：执行一些非攻击的效果。
- 付与：一些有延迟效果或光环的牌。有属性“纳X”。纳是一个非负整数，打出这张牌时将这张牌放到付与区，然后从虚和/或自装上取出总计X片樱花结晶（这些樱花结晶被称作“献”）放到这张牌上。当这张牌上没有樱花结晶的一刻，此牌进入弃牌堆。如果虚加上自装不够X，则尽量多的移动；如果虚加上自装的数值为0，则此牌打出就进入弃牌堆。

次要类别（牌可以没有次要类别）
- 全力：要打出全力牌，整个主要阶段就不能打出其他牌或执行基本动作。换言之，如果该主要阶段内打出了其他牌或执行了基本动作，则不能打出全力牌。
- 对应：在对手攻击时（该攻击可能是生成的虚拟攻击），可以打出有该词条的牌，并优先于被对应的攻击牌结算效果。对应牌也可以在自己的回合中正常打出。如果一张牌是对应打出的，则该牌不能被对应；也不能用多张对应牌对应同一个攻击。

攻击牌记录例：
- 斩：【3-4 3/1】（一个白板的，3-4距离的攻击，伤害为3/1）
- 一闪：【3 2/2】决死～该攻击获得+1/+0。（此牌攻击距离为单距3。“决死”是一个条件发动的被动技能。）
- 八面斩：【4-5 2/1】攻击后：八相～进行攻击【4-5 2/1】。（“八相”是一个条件发动的被动技能，这说明该牌可以衍生攻击）
- 居合：全力【2-4 4/3】若当前距离小于等于2，该攻击获得-1/-1。（一个全力攻击，当距离短时伤害会下降）
- 薙刀斩：对应【4-5 3/1】（一个白板的对应攻击）

付与牌记录例：
- 圈域：【纳2】达人距离扩大1。本牌上的樱花结晶在被移除时，移到距（而非虚）。（常规的光环效果）
- 冲音晶：对应【纳1】展开时：被对应的攻击获得-1/+0。弃置时：进行攻击【0-10 1/-】不可对；然后1虚到距。（付与也可以用来对应。这个付与没有光环，只有打出时和弃置时效果）
- 气焰万丈：全力【纳4】你来自其他女神的攻击牌获得+1/+1和超克。（付与牌也可以是全力）

行动牌记录例：
- 身法：本回合内，你的下一次攻击获得距离扩大（远1）。若你的命少于对方，则执行至多2次基本动作。（没有立即跟出攻击伤害或纳，那么这就是行动。这是很普通的行动）
- 诗舞：对应。获得1集中力，选择：1自气到自装，或1自装到距。（普通的对应行动）
- 识破：1距到虚。八相～本牌可以像对应牌一样打出。（这不是对应牌，但在某些情况下可以用来对应）
- 扇回旋：全力。从你的弃牌堆和盖牌堆中选择攻击至多2张牌，以任意顺序放置于你的抽牌堆底。2虚到自装。（普通的全力行动）

### 切牌

切牌与基础牌的效果没有任何区别，只是多了一个属性“耗能X”。切牌永远不会进入弃牌堆、抽牌堆、手牌等。

要打出切牌，需要将X个樱花结晶从自气移到虚，如果自气不足X则不能打出。随后将该切牌在切牌区从背面向上翻到正面向上，并执行其效果。

切牌可能具有永续的光环效果。

切牌在使用完毕后，如无特殊说明不能使用第二次。

切牌记录例：
- 月影落（7）：【3-4, 4/4】（普通的白板攻击。7气）
- 浦波岚（3）：对应【0-10 2/-】攻击后：被对应的攻击获得-2/+0。（普通的对应攻击）
- 浮舟宿（2）：5虚到自装。即再起：当你的命从大于等于4降到小于等于3时。（普通的行动。即再起是一个特殊词条）
- 天音摇波的潜力（5）：全力【1-4 5/5】。只能在决死时打出。（一种有限制的攻击）
- 音无碎冰（2）：对应【0-10 1/1】攻击后：被对应的攻击获得-1/-1。再起：八相。（切牌也可以是对应）
- 无常其心（3）：全力【纳7】伞和簪现在共享攻击距离。（切牌也可以是付与）
- 独奏·冻鸣雪花（0）：你受到1装伤。使用后：所有试图将樱花结晶移动到装的基本动作或牌效，都会改为移到虚。即再起：你受到1点命伤时。（“使用后”即永续的光环效果：只要这张牌正面向上就有这个效果。）

### 词条说明

为了节约记录空间，用部分词条记录部分常见效果是常规操作。以下是常见词条。

- nAA到BB：按指定的要求尽量多的移动樱花结晶。
- 畏缩：下次获得集中力时，改为不获得，然后脱离畏缩状态。
- 焦躁：受到无来源的1/1伤害。
- 终端：打出这张牌时，结束你的主要阶段。如果你在对手的回合打出了终端牌，那么你在本阶段的剩余时间中不能对应。
- 超克：附加在攻击上，意思是X/Y的攻击伤害中X可以大于5。
- 不可对：附加在攻击上，意思是这次攻击不可被对应。
- 锁定：附加在攻击上，意思是这次攻击一旦被打出，则此次攻击即使因为被对应而不满足攻击距离，仍然能够打到。（如果本来就打不到，那么这个攻击牌也不能被打出）
- 打消被对应的攻击：这个词条只会在具有对应副类别的牌上出现，意思是打消这个攻击的伤害和附加效果。
- 破绽：这个词条只会在付与牌上出现，意思是在这张付与牌展开时如果受到了任何命伤（重铸牌库除外）则将该付与牌上的所有樱花结晶移到虚、将该付与牌盖伏并不执行其弃置时效果。
- 再起：这个词条只会在切牌上出现。在该切牌持有者的回合结束阶段，如果一张已使用状态的切牌满足“再起”后面的条件，则将该切牌重置为未使用状态。不能故意不再起。
- 即再起：这个词条只会在切牌上出现。在任意时刻，只要满足“即再起”后面的条件，该切牌就会立刻重置为未使用状态。不能故意不即再起。
